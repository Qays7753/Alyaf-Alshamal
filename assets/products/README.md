# صور المنتجات

هذا المجلد يحتوي صور الأصناف اللي بتظهر بكبسة الصورة جنب كل صنف.

## الخطوات

### 1. حضّر الصور الأصلية

حط الصور الأصلية (JPG / PNG / HEIC / أي صيغة) داخل مجلد باسم `raw/`
داخل هذا المجلد، وسمّيها بمعرّف الصنف مع رقم:

```
assets/products/raw/rocket-1.jpg
assets/products/raw/rocket-2.jpg
assets/products/raw/tomato-1.png
```

معرّفات الأصناف (`id`) موجودة في `assets/products.js`:

| المعرّف | الصنف | | المعرّف | الصنف |
|---|---|---|---|---|
| `lettuce-strips` | خس شرحات | | `parsley` | بقدونس مفروم |
| `lettuce-salad` | خس سلطة | | `rocket` | جرجير |
| `iceberg` | خس آيسبرغ | | `spinach` | سبانخ |
| `lollo-bionda` | لولو بيندا | | `sweet-pepper` | فلفل حلو |
| `lollo-rosso` | لولو روسو | | `hot-pepper` | فلفل حار |
| `cabbage-strips` | ملفوف شرحات | | `tomato` | بندورة |
| `red-cabbage` | ملفوف أحمر | | `cherry-tomato` | بندورة كرزية |
| `onion` | بصل مقطّع | | `mushroom` | فطر مقطّع |
| `carrot` | جزر شرحات | | `basil` | ريحان |
| `baby-leaves` | بيبي ليڤز | | | |

### 2. حوّل الصور واضغطها

```bash
bash tools/optimize-images.sh
```

السكربت بيحوّل كل صورة في `raw/` إلى **WebP** بعرض أقصى 1200px وجودة 82،
وبيحفظها هنا مباشرة بنفس الاسم، وبيطبع لك السطر الجاهز للصق.

### 3. اربط الصور بالصنف

افتح `assets/products.js` واكتب أسماء الملفات داخل `images`:

```js
{ id: "rocket", name: "جرجير", pricePerKg: 4.50, packs: [100],
  images: ["rocket-1.webp", "rocket-2.webp"] },
```

خلص — الكبسة رح تظهر الصورة الأولى كمصغّرة، والكبس عليها بيفتح المعرض
مع أسهم للتنقّل بين صور نفس الصنف.

## ملاحظات

- الصنف اللي ما إله صور بتظهر جنبه كبسة فاضية بأيقونة صورة.
  لإخفائها كلياً: غيّر `HIDE_EMPTY_IMAGE_BUTTONS` إلى `true` في `products.js`.
- الأفضل تكون الصورة مربعة أو 4:3، والمنتج واضح على خلفية بسيطة.
- خلّي حجم الملف الواحد أقل من 150KB عشان الصفحة تضل خفيفة على الموبايل.
